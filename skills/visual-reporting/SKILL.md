# Visual Reporting

Use this skill after authoritative tool data has been collected.

1. Identify the decision or comparison the user needs to understand.
2. Preserve source values; do not invent or interpolate missing data.
3. Call `chart.generate` only when a chart materially improves comprehension.
4. Prefer bar charts for comparisons, lines for time series, scatter plots for relationships, and pie/donut charts only for small part-to-whole sets.
5. Return one composed response containing a concise conclusion, key evidence, limitations, sources, and the relevant chart blocks.

Charts supplement the written conclusion and never replace provenance or accessibility text.
